# LymeFiber.net

Static site for LymeFiber, built with [Astro](https://astro.build) from Markdown and edited through Sveltia CMS at `/admin/`.

- `npm run dev`: local preview at http://localhost:4321
- `npm test`: unit and build-output tests
- `npm run build`: build to `dist/`
- `npm run check`: link and redirect report

See `EDITING.md` for editors and `HANDOFF.md` for account details. The design is in `docs/superpowers/specs/`.
