# cms-auth

The small Cloudflare Worker that handles "Sign in with GitHub" for the site editor at `/admin/`.
It is a pinned copy of [sveltia-cms-auth](https://github.com/sveltia/sveltia-cms-auth) (commit `7c34594`, MIT).
It is deployed separately from the website; see `wrangler.toml` for the commands and `HANDOFF.md` for the account details.
