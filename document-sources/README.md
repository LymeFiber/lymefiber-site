# Document sources

Microsoft Word originals of the PDFs in `public/documents/`.

This folder is **not** published on the website. Only the PDFs in
`public/documents/` are visible to the public.

## Naming

Give each Word file the same name as the PDF it produces, e.g.

    document-sources/LymeFiber-Privacy-Policy.docx
    public/documents/LymeFiber-Privacy-Policy.pdf

## Updating a document

1. Edit the `.docx` here and save it back to this folder.
   NOTE: If there is a material change to the document,
   update the date shown at the end of the document.
2. Export it to PDF.
3. In the site editor (Documents → Policies & Documents), upload the PDF
   **with the same file name** so existing links keep working.
4. Change the entry's "Last updated" date.

## Alternate update mechanism

If you can modify/push to the Github repo,
edit the documents locally, save their PDFs,
and push the entire repo.
